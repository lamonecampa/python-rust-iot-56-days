# Python & Rust for IoT: 56-Day Learning Path

Kurikulum intensif pemula selama 8 minggu, 1–2 jam per hari. Python dipelajari pada hari 1–28, Rust pada hari 29–49, dan integrasi proyek pada hari 50–56.

Materi lengkap sedang disusun dalam direktori `curriculum/`, `python/`, `rust/`, `capstone/`, dan `assessments/`.
