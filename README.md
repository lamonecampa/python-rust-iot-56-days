# Python & Rust for IoT: 56-Day Curriculum

Kurikulum 8 minggu untuk pemula absolut, dengan pendekatan visual-first. Python hari 1–28, Rust hari 29–49, dan integrasi hari 50–56.

## Mulai belajar

1. Baca [Standar Pembelajaran Ramah Pemula](docs/PEDAGOGICAL-STANDARD.md).
2. Mulai dari [Tutorial Visual Block](docs/VISUAL-BLOCK-TUTORIAL.md).
3. Pelajari [Tutorial Python Visual](docs/PYTHON-VISUAL-TUTORIAL.md).
4. Lanjutkan ke [Tutorial Rust Terapan](docs/RUST-TUTORIAL.md) dan [Panduan Visual Konsep Rust](docs/RUST-VISUAL-GUIDE.md).
5. Coba [Visual Lab Interaktif](visual-lab/index.html) untuk mengubah input, menjalankan simulasi logika, dan memprediksi output.
6. Ikuti [Evaluasi Mingguan dan Panduan Praktik](docs/LEARNING-ASSESSMENT.md).

## Metode belajar

**Konteks nyata → Visual Block → Algoritma → Flowchart/Pseudocode → Prediksi → Kode → Simulasi → Debugging → Evaluasi.**

Visual Lab merupakan simulator logika edukatif, bukan compiler Python/Rust. Kode harus tetap dijalankan di interpreter/compiler yang sesuai. Capstone awal memakai data simulasi; integrasi perangkat fisik dan deployment produksi adalah tahap lanjutan.
